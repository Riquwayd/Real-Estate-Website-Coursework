# 🏠 Real Estate Platform

Веб-платформа для пошуку, купівлі та оренди нерухомості.
Проєкт розроблений як курсова робота для демонстрації навичок Full Stack розробки (PHP + JS + SQL).

Система дозволяє користувачам шукати житло за допомогою інтерактивної карти, фільтрувати оголошення, реєструватися та додавати власні об'єкти нерухомості.

## 🛠 Технології (Tech Stack)
Проєкт написано на чистому PHP (Native), без використання важких фреймворків, щоб показати розуміння принципів роботи веб-застосунків.

* **Backend:** PHP (PDO), MySQL / MariaDB
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Map & Geo:** Leaflet.js + OpenStreetMap (пошук за радіусом)
* **Async:** AJAX (Fetch API) — оновлення контенту без перезавантаження
* **Tools:** Composer, XAMPP

## ⚙️ Функціонал

### 🔹 Для Користувачів
* **Розумний пошук:** Фільтрація за ціною, кількістю кімнат, типом (оренда/продаж).
* **Пошук на карті:** Вибір зони та радіусу пошуку (реалізовано через формулу Гаверсинуса).
* **Особистий кабінет:** Реєстрація, вхід, редагування профілю та фото.
* **Управління оголошеннями:** Можливість додавати власні об'єкти ("Sell Property"), завантажувати галерею фото.
* **Безпека:** Відновлення паролю через Email (код підтвердження).

### 🔹 Для Адміністраторів
* **Управління новинами:** Створення, редагування та видалення новин.
* **Банери:** Налаштування рекламних блоків на головній сторінці.
* **Модерація:** Керування контентом та користувачами.

## 📂 Структура Бази Даних
* `users` — користувачі та адміністратори.
* `properties` — оголошення (ціна, опис, координати).
* `property_photos` — фотографії об'єктів.
* `news` — новини сайту.
* `site_settings` — налаштування.

## 🚀 Як запустити проєкт (Installation)

1.  **Клонуйте репозиторій:**
    ```bash
    git clone [https://github.com/Riquwayd/Real-Estate-Website-Coursework.git](https://github.com/your-username/Real-Estate-Website-Coursework.git)
    ```

2.  **База даних:**
    * Створіть базу даних у phpMyAdmin (наприклад, `real_estate`).
    * Імпортуйте файл `real_estate.sql` (знаходиться в корені проєкту).

3.  **Налаштування:**
    * Відкрийте файл `db_config.php`.
    * Вкажіть ваші дані для підключення до БД (host, dbname, user, password).

4.  **Запуск:**
    * Розмістіть папку проєкту на локальному сервері (наприклад, у папці `htdocs` для XAMPP).
    * Відкрийте в браузері: `http://localhost/real_estate`
